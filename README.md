# johnwayder.com

Website pessoal de John Wayder — Senior Web Developer.

Site estático (HTML, CSS e JavaScript puro) one-page, com suporte a pt-BR e
en-US, hospedado via GitHub Pages no domínio [johnwayder.com](https://johnwayder.com).

## Estrutura

```
index.html          Página única com todas as seções
assets/css/          Estilos
assets/js/           Scripts (i18n e interações)
assets/img/          Imagens
```

## Desenvolvimento

Abra o `index.html` diretamente no navegador ou sirva a pasta com qualquer
servidor estático.
